# EBT-Q0-TP-001 — bench qualification protocol (draft, NOT authorized)

**Purpose:** transform advertised makerspace capability into a measured and safety-reviewed experimental setup. No powered work can be performed on this draft alone.

**Stage Q0-A — access:** facility, booking, induction, allowable test class, available power, permitted sample storage, public-data/photo rights, qualified supervisor, lab restrictions. Stop if no permission for powered tests.

**Stage Q0-B — inventory:** serial/model/range/resolution, working condition, last calibration/reference certificate if accessible, spare probes, logger timebase, sensors, isolation and current limits. Inspect before buying.

**Stage Q0-C — unpowered rig review:** schematic and physical inspection; correct wiring, continuity/polarity; protective components, conductors, mount/material compatibility, disable switch, guarded heated areas; local risk review.

**Stage Q0-D — sensor verification:** comparison with suitably qualified electrical and temperature references at multiple points in intended range; correction uncertainty, drift, response time and timestamps. Record *verification* if no traceable calibration chain.

**Stage Q0-E — resistive thermal pilot:** under facility supervision/authorization, step safe dissipated power through approved bounded values; record true dissipated V(t)I(t), case/sink/ambient temps, cool-down, drift, and safety trips. Define stabilization empirically. Stop on cable/fixture heating or instrument saturation.

**Stage Q0-F — repeatability and lock:** independent reassembly cycles with same settings, pilot variance, run time, power sensitivity and a justified sample count. Create readiness report and obtain actual go/no-go signoff before MOSFET campaign.

**Release evidence:** signed/recorded site authorization, equipment register, schematics, risk assessment, calibration references, raw pilot data and quality flags, uncertainty budget and G2/G3 gate record.
