# Electronics Bench Testing

**Open experimental and computational research in electrothermal characterization, measurement uncertainty and electronics cooling.**

This repository is being initialized with the controlled master programme baseline **EBT-PMP-001 v1.0 (5 November 2026)**. A complete reproducible source import is being prepared on a review branch.

**Current evidence level:** independent research planning and synthetic feasibility modeling only. No powered experiments, KTH institutional affiliation or authorization, traceably calibrated measurements, peer review, or completed thesis are claimed.

The programme will preserve verified results, uncertainty and limitations; physical testing is subject to laboratory authorization and safety readiness reviews.

For the controlled project record, see the initial source import PR once available.
