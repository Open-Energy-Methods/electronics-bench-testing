# Contributing and reproducing

This programme is currently independent research planning and verified **synthetic** feasibility, not an experimentally validated semiconductor result. Contributions are welcome after review.

- Propose methodology changes using `06_templates/change_request.md` and log them in `08_project_controls/change_requests.csv`.
- Keep raw experimental files immutable; submit derived-analysis changes as versioned scripts, never rewrite measurements.
- Preserve provenance (synthetic vs physical), instrument range, reference uncertainty and analysis dependencies.
- Identify applicable standard editions and never claim conformity without a full applicable method review.
- New experiments require actual local permissions, approvals and safe review. Contributions do not authorize bench operation.
- Pull requests should include tests and explain which requirements and figures they affect.
- Before release, resolve rights/permission for images, hardware specifications and facility metadata.
