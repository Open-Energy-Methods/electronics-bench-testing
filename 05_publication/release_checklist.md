# EBT open research release gate (draft)

- [ ] Permission to publish facility-derived results, photos and instrument metadata recorded.
- [ ] Real vs synthetic data have unambiguous metadata and separate folders.
- [ ] All raw files immutable, SHA-256 checksums verified, full dataset manifest present.
- [ ] Code runs on clean environment with locked dependencies and test report.
- [ ] Figures and paper statistics recreated from released inputs, not manually transcribed.
- [ ] Experiment configuration, sensors, reference chain, uncertainty and deviations disclosed.
- [ ] Peer reproduction attempt or documented solo clean-environment reproducibility check.
- [ ] Authors/contributors/affiliation permission and institutional acknowledgments correct.
- [ ] Literature, manufacturer datasheets, standards and third-party material properly cited/licensed.
- [ ] Manuscript conclusion constrained to measured variables, states and conditions.
- [ ] GitHub tag, CITATION.cff, LICENSE, data dictionary and Zenodo metadata aligned.
- [ ] Zenodo DOI attached only after actual deposit; never invent DOI or imply peer review.
- [ ] LinkedIn/post figures show verified results and include limitations and reproduction links.
