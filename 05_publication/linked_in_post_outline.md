# LinkedIn communication scaffold — DO NOT POST BEFORE RESULTS

Hook: the measured technical question rather than inflated accuracy claims.

1. Engineering problem and why thermal designers care.
2. One labeled photo of the approved setup (permission required) and traceability chain.
3. A plot from actual measured data showing result + uncertainty + any disagreement.
4. One paragraph on model limitations, sensor placement, failure modes and alternatives.
5. Clear contribution attribution: what I designed, measured, verified and analyzed.
6. Reproduce it: link to stable public GitHub tagged release and exact Zenodo DOI (once created).
7. Invitation to inspect, independently reproduce, or critique.

Never present a simulation from the v0.1 package as the physical outcome. Not every milestone warrants a LinkedIn post.
