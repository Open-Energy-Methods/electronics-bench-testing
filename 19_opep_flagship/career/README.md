# OPEP career-to-competency development plan (004)

18 November 2026 | planning and public source evidence only.
This is an industrial skills and experimental work-sample programme, not a
recruitment dossier. Public advertisements are paraphrased and referenced in
OPEP-JOB-004_public_role_matrix.csv. Roles include historical advertisements
and visible current employer pages; visibility is not a vacancy guarantee.
Private applications, email IDs, responses and interview records must remain
outside this public repository. A work sample cannot substitute for required
years of experience, formal qualifications, language, security screening,
work authorization or regulated-sector competence.

The original fifteen modules remain authoritative. Twelve cross-disciplinary
campaigns allocate work across them rather than adding redundant top-level
modules. See campaign registry, technical scopes, facility acquisition plan
and draft DVP&R. Each campaign requires its own readiness review, actual
facility permission, inspected equipment and accepted conditions before use.
No manufacture, measurements, purchases, grants, endorsements or safety
approval are claimed. One active compact module plus common hardware must fit
the measured KTH project box or use separate permitted facility storage.

2. C02/C04 elastic structural and modal study, using an approved test

   validation; optional separate acoustic module C05.

4. C07 approved cold open-water thermal-hydraulic analogue, then C06/C07
   approved heat only when a suitable facility and commercially manufactured
   equipment exist.

   offline exchange as described in the existing OPEP-DT-003 document.
C09 assurance is continuous. C12 is optional and never used to claim code
qualification. Each release can be published separately.
